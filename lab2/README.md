### Архитектура и принцип работы

Приложение представляет собой валютный конвертер, в котором есть
три изменяем поле ввода: если одно из них изменится - автоматически 
и изменится следующие два.

**Логика работы:**

1. Для ввода используются обычне однострочные текстовые поля, к 
которым подключен валидатор. Он разрешает вводить только 
положительные дробные числа (`QLineEdit` + `QDoubleValidator`).
2. Защита от зацикливания (`blockSignals`):
    - При событии `textChanged` на поле `USD` програмно 
    меняем `.setText()` у `RUB` и `EUR`.
    - Изменение текста вызывает `textChanged` уже для `RUB` и `EUR`,
    что вызвало бы бесконечную рекурсию.
    - `field.BlockSignals(True)` временно отключает испускание 
    сигналов для редактируемых полей во время обновления значений,
    а `blockSignals(False)` затем возращает их в рабочее состояние.
3. Переменная текста заменяет `,` на `.`, чтобы ввод был корректен.
